# Calcolatore Interesse Composto

MVP statico, senza account, database, backend, cookie o raccolta dati.

## Deploy
Carica questa cartella su GitHub e pubblicala con GitHub Pages, oppure trascinala su Cloudflare Pages/Vercel.

## Prima fase
- Validare traffico organico e condivisioni.
- Misurare click su eventuali link affiliati solo dopo aver scelto un provider.
- Non aggiungere account o backend finché non esiste domanda.
